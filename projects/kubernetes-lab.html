CLOUD & DEVOPS BOOTCAMP PROJECT

PortCheck

Network Port Scanner

A lightweight Linux networking tool that scans a target host for open TCP ports and presents detected services with basic risk guidance.

Linux Bash Python Flask Netcat Networking DevSecOps
01 / PROJECT

From a Bash script to a simple network utility.

The original bootcamp task was to build a Bash script that accepts an IP address and port and uses Netcat to check whether the port is open.

I extended the task with a Flask interface that can check a controlled set of TCP ports and present the results in a more readable way.

02 / HOW IT WORKS

Simple underneath.

01

Validate

Validate the target and port values before they reach the backend scanner.

02

Scan

A Bash script uses Netcat to test TCP connectivity against the selected ports.

03

Analyse

Detected ports are mapped to common services and basic exposure guidance.

04

Present

Flask returns the results through a clean web interface.

User → Flask → Bash → Netcat → Results
03 / VERIFICATION

Checking the scanner against Ubuntu.

I compared the ports detected by PortCheck with the listening TCP services reported directly by Ubuntu using ss.

04 / DEVSECOPS

User input should never become a shell command.

01

Input Validation

Host and port values are checked before execution.

02

Controlled Ports

Port values are restricted to valid TCP port numbers.

03

Safe Execution

Values are passed as subprocess arguments instead of constructing a shell command from user input.
