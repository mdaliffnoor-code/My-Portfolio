## Important: `base.html`
`base.html` is included as the common page/layout reference requested for the assignment. Because GitHub Pages serves static HTML and does not process Flask/Jinja template inheritance, the publishable pages already contain the shared navigation/footer markup. If this portfolio is later converted into Flask, `base.html` can be moved into `templates/` and the pages can use `{% extends "base.html" %}`.
